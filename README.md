# Anamnese PSI — protótipo

**Não validado. Somente dados fictícios; não usar para atendimento, diagnóstico ou decisões clínicas.** Resumos, referências, regras e instrumento requerem revisão técnica e de direitos autorais antes de qualquer outro uso.

Cópia local do projeto Virlene no commit `edc31f699881d209b3b4dddd535ad056ced8578a`; não modifica nem publica o original.

O rascunho e as anamneses são armazenados no navegador, sem criptografia. Os dados podem ser perdidos ao limpar o armazenamento. Navegadores e origens diferentes não compartilham dados automaticamente; não há importação ou exportação nesta versão. O histórico guarda uma versão anterior ao atualizar um registro salvo. O cache do PWA funciona offline após uma primeira abertura online em HTTPS ou localhost.

A escala parcial exibe os itens faltantes, e um domínio incompleto abaixo do limite é inconclusivo. Marcações não são diagnóstico e não marcado não significa negativo. Anotações, hipóteses e alternativas são inseridas pela pessoa que testa.

A escala mantida do projeto original é atribuída à American Psychiatric Association; condições de uso e reprodução devem ser verificadas antes de disponibilização ou uso comercial.

Os registros desta cópia são separados dos dados do Virlene original. Não há migração automática.
